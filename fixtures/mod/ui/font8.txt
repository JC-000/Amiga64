# fixtures/mod/ui/font8.txt - W15-U: the player UI's 8x8 font (docs/UI_READABLE.md
# rules F1-F3).
#
# Provenance (fix round 1, 2026-10-12): drawn for this project in its own
# proportions - glyphs 7 pixels wide (columns 0-6) with 3-pixel counters,
# square letterforms with chamfered corners, 2-pixel vertical strokes.  The
# first version of this file (Wave 15 U0) was NOT original: it reproduced the
# C64 character ROM's upper-case set from memory (36 of 63 glyphs identical),
# which broke the clean-room rule; see build/evidence/w15-ui/PROGRESS.md.
# tests/run_modui.py --font-vs-rom checks every glyph against the local ROM
# (VICE install, never copied): >= 8 pixels apart under +-1-pixel shifts,
# except the space, '-' and '.' (justified in PROGRESS.md).
#
# One glyph per block: a "= <code> <name>" line, then 8 rows of 8 pixels
# ('#' set, '.' clear).  Pixels are C64 hires pixels; on the Amiga each is
# 2 hires pixels (the 320-px grid).  Codes 32-95 are ASCII; 'a'-'z' fold to
# 'A'-'Z'; 128-130 are player symbols; bytes below 32 show as spaces and
# anything else as '?'.  host/ui_preview.py reads this file; the 68k font
# table (font.i) is generated from it.
